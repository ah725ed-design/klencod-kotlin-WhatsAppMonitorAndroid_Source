# WhatsApp Monitor — مشروع أندرويد تجريبي

هذا مشروع مصدر لتطبيق أندرويد يلتقط **نص إشعارات واتساب الظاهرة على جهازك فقط**، ويحفظها محلياً، ويرسلها إلى بوت تليجرام إذا أُدخلت بيانات البوت.

## الحدود والخصوصية
- لا يقرأ قاعدة بيانات واتساب ولا يسترجع الرسائل التي حُذفت قبل وصول إشعارها.
- لا يفتح ولا يستخرج صور/فيديوهات View Once.
- قد لا يظهر نص الرسالة إذا كانت معاينة الإشعارات مخفية أو كان الهاتف لا يعرض محتوى الإشعار.
- قد يلتقط إشعارات المجموعات أيضاً.
- لا تشارك Bot Token مع أي شخص. من يملكه يمكنه التحكم في البوت.
- التطبيق لا يرسل شيئاً إلى تليجرام قبل إدخال التوكن و Chat ID. تخزين التوكن هنا داخل مساحة التطبيق الخاصة، لكنه ليس مشفراً؛ استخدم بوتاً مخصصاً ولا تشارك الهاتف.

## الإعداد
1. افتح Telegram وأنشئ بوتاً عبر `@BotFather` ثم انسخ Bot Token.
2. افتح محادثة البوت واضغط Start.
3. للحصول على Chat ID، افتح هذا العنوان في المتصفح بعد استبدال TOKEN بالتوكن:
   `https://api.telegram.org/botTOKEN/getUpdates`
   ابحث عن `message` ثم `chat` ثم `id`. لا تشارك الرابط أو نتيجته مع أحد.
4. افتح المشروع في Android Studio، ثم شغّله على هاتفك.
5. أدخل Bot Token و Chat ID في التطبيق واضغط حفظ.
6. اضغط تفعيل صلاحية الوصول للإشعارات، ثم فعّل WhatsApp Monitor من إعدادات أندرويد.
7. تأكد أن معاينة رسائل واتساب مفعّلة في إعدادات إشعارات واتساب وأندرويد.

## البناء
افتح المجلد في Android Studio حديث، واترك Gradle يزامن المشروع، ثم اختر Build > Build APK(s).
الحد الأدنى Android 8.0 (API 26).

هذا نموذج أولي يحتاج اختباراً على جهازك وإصدار أندرويد لديك قبل الاعتماد عليه.
